## Visual journey

I installed WSL on my Windows host computer and then ran a linux environment on it to view live updates to my files in vscode as I save them.

![WSL Run Command]({{site.baseurl}}/images/WSL_Run.png)

| Command | What it does |
|---------|---------------|
| `cd opencs/student` | Moves into the `opencs/student` directory |
| `source venv/bin/activate` | Activates the Python virtual environment named `venv` |
| `code .` | Opens the current directory in VS Code |
